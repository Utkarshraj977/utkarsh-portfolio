# Vivek Kumar Jain Portfolio

Tailwind CSS + React + Vite portfolio recreated around the supplied reference video layout.

## Run

```bash
npm install
npm run dev
```

## Stack

- React
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Icons

The portfolio uses Vivek Kumar Jain's project, achievement, skill, social and contact data.
